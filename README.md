# Clinical Data Validation Project

A mini clinical data management project: validate a **synthetic** clinical trial dataset (Demographics, Adverse Events, Labs) using **Python (pandas)** and **SQL**, and raise data queries like a Clinical Data Associate / Analyst.

> All data is synthetic and generated by `generate_data.py`. No real patient data is used.

## Why this project
In real trials, clinical data managers clean data by running edit checks and sending queries to sites. This project simulates that workflow end to end.

## Workflow
1. `generate_data.py` creates DM, AE and LB datasets (SDTM-style variable names) with deliberately injected errors.
2. `validate.py` runs pandas edit checks and writes `output/mock_queries.csv` (one query per issue, with site-ready query text).
3. `sql/checks.sql` + `run_sql_checks.py` run the same style of checks in SQL (SQLite), plus summary listings.
4. Findings are summarised by check type and by site (query burden).

## Checks implemented
| Check | Domain | Example |
|---|---|---|
| Orphan subject | AE | AE record for a subject not in DM |
| Missing value | AE, LB | Missing severity, missing lab result |
| Date before consent | AE, LB | Event/lab dated before informed consent |
| End before start | AE | AE end date earlier than start date |
| Duplicate record | AE | Same AE entered twice |
| Range check | DM | Age <18 or implausible (e.g., 150) |
| Plausibility | LB | Hemoglobin of 140 g/dL (likely entry error) |

## How to run
```bash
pip install pandas numpy
python generate_data.py
python validate.py
python run_sql_checks.py
```

## Sample results
26 queries raised across 9 check types, e.g. `AE start before consent`, `HGB implausible`, `duplicate AE`. See `output/mock_queries.csv`.

## Possible extensions
- Power BI dashboard: query counts by site and check type, query aging, data completeness.
- Map the data to proper SDTM domains and validate against CDISC rules.
- Add checks: SAE reporting consistency, lab values outside normal range (clinical significance listing), visit window deviations.
- Re-implement the checks in R (tidyverse).

## Skills demonstrated
Data cleaning and validation, SQL (joins, GROUP BY/HAVING), Python (pandas), edit-check logic, query writing, clinical data concepts (consent, AE, SAE, labs, orphan records).
